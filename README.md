## 📖 Sobre

Este repositório reúne as minhas resoluções da lista de exercícios de algoritmos da
**FACCAT (Faculdades Integradas de Taquara)**.

É uma **atividade de estudo** do curso de lógica de programação. Os exercícios começam
em operadores aritméticos e vão até estruturas de seleção aninhadas e operadores lógicos.

Cada exercício está em um arquivo `.alg` separado, pronto para abrir e rodar no VisuAlg.

---

## 🗂️ Estrutura

```
faccat/
├── E05 – E11  → Operadores aritméticos
├── E12 – E13  → Horizontalização de fórmulas
├── E14 – E26  → Seleção simples e operadores relacionais
└── E27 – E39  → Seleção aninhada, concatenada e operadores lógicos
```

## 🚀 Como executar

1. Baixe e instale o **[VisuAlg](https://visualg3.com.br/)**
2. Clone este repositório:
   ```bash
   git clone https://github.com/seu-usuario/seu-repositorio.git
   ```
3. Abra o VisuAlg e vá em **Arquivo → Abrir**
4. Escolha um dos arquivos `.alg`
5. Aperte **F9** para executar ▶️

## 🎯 O que eu pratiquei

- ✅ Variáveis e tipos (`inteiro`, `real`, `caractere`, `logico`)
- ✅ Entrada e saída de dados (`leia`, `escreva`, `escreval`)

- ✅ Operadores relacionais (`> < >= <= = <>`)
- ✅ Operadores lógicos (`e`, `ou`, `nao`)
- ✅ Seleção simples e composta (`se...entao...senao`)
- ✅ Seleção aninhada e concatenada
